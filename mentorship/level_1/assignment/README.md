# Выполнение 1-ого уровня: анализ 

## Описание проекта

В рамках проекта проводится анализ датасета о пассажирах «Титаника». Цель работы - применить изученные базовые методы теории вероятностей, статистики для анализа данных, научиться использовать библиотеку pandas для работы с данными.

## Используемые инструменты

- ЯП Python
- Библиотека Pandas
- Jupyter Notebook

## Выполненные задания

1. Подсчёт общего количества пассажиров, выживших и погибших.
2. Расчёт вероятности и доли выживших пассажиров.
3. Расчёт мат.ожидания, дисперсии и СКО.
4. Расчёт условной вероятности выживания в зависимости от пола пассажира.

## Данные

Используется датасет `titanic.csv`, содержащий информацию о пассажирах, в том числе их поле и факт выживания.

## Структура проекта

- папка `level_1` - содержит файл задания 1-ого уровня.
- `titanic_analysis.ipynb` - код, расчёты и результаты анализа.
- `README.md` - описание проекта.

## Результаты

В ходе работы рассчитаны основные показатели выживаемости пассажиров и условные вероятности выживания для мужчин и женщин.
